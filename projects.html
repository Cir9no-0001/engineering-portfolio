Active Directory Home Lab

Down

July 2025

An Active Directory security/networking lab built on VirtualBox using a Windows Server 2019, a Windows 10 workstation, and Kali Linux attacker to simulate an enterprise network. The lab was built by configuring Active Directory Domain Services, implementing Group Policy, and testing authentication vulnerabilities through controlled password spraying. This project was designed to develop practical experience with enterprise network infrastructure and understand the defensive side of CTFs by exploring how security policies mitigate common attack techniques.

Simon Says V2

Completed

January 2024

An Arduino-based memory game inspired by the classic Simon Says toy, designed and simulated using Tinkercad Circuits before being built through custom circuitry and 3D-printed components. Simon Says 2 was created to explore embedded systems, hardware-software integration, and interactive design by combining LED patterns, audio feedback, and user controls into an engaging cognitive training experience. The project aimed to create a fun and progressively challenging game while applying principles of circuit design, programming, and physical prototyping.

  • Arduino
  • C++
  • Tinkercad

CodeAtlas

In Progress

July 2026

An automated LeetCode solution synchronization tool that retrieves accepted SQL submissions, organizes solutions, manages documentation, and tracks programming progress through GitHub Actions and Leetcode's GraphQL API. CodeAtlas was built to allow developers to document their coding journey, track their progress, and maintain a well-organized repository of their coding solutions with the eventual goal of syncing problems from across the biggest competitive programming platforms.
